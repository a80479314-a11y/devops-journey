# 🐚 Bash и Терминал — Основы автоматизации

*Автор: amal-devops | Обновлено: 2026-11-13*

---

## 1. Зачем нужен терминал?

Терминал — это главный инструмент DevOps-инженера. 
**Главное правило:** Если задачу нужно сделать больше одного раза — её нужно автоматизировать (написать скрипт).

### Что работает из терминала?
Почти все современные DevOps-инструменты управляются через командную строку:
- **Git** — контроль версий
- **Docker / Kubernetes** — контейнеры и оркестрация
- **Terraform / Ansible** — инфраструктура как код
- **Python** — скрипты автоматизации
- **curl, ping, tcpdump** — работа с сетью

---

## 2. Терминал vs Оболочка (Shell)

Важно различать два понятия:
- **Терминал** — это программа-окно (эмулятор), через которое мы общаемся с системой.
- **Оболочка (Shell)** — это программа-интерпретатор, которая понимает твои команды и выполняет их.

Самая популярная оболочка в Linux — **Bash**. Но есть и другие: `zsh`, `tcsh`, `fish`.

## 3. Как превратить текст в скрипт?

Любой текстовый файл становится скриптом при выполнении двух условий:

1.  **Shebang (Sha-Bang):** Первая строка файла должна указывать, какой интерпретатор использовать.
```bash
    #!/bin/bash
```
    *(Это наследие UNIX с 1989 года. Без этой строки система не поймет, чем открывать файл).*

2.  **Права на исполнение:** Файлу нужно дать разрешение на запуск.
```bash
    chmod +x script.sh
    # или более точно:
    chmod u+rx script.sh
```

После этого всё содержимое файла будет выполняться как список команд сверху вниз.

## 4. Служебные символы (Синтаксис)

Эти символы — "грамматика" Bash. Их нужно знать наизусть.

| Символ | Название | Что делает | Пример |
| :--- | :--- | :--- | :--- |
| `#` | Комментарий | Всё после него игнорируется | `# Это пояснение` |
| `;` | Разделитель | Выполняет команды последовательно | `cd /tmp; ls -la` |
| `\|` | Pipe (Труба) | Передает вывод одной команды на вход другой | `cat file.txt \| grep "error"` |
| `>` | Перенаправление | Записывает вывод в файл (**перезаписывает**!) | `echo "Hi" > file.txt` |
| `>>` | Дописывание | Добавляет вывод в конец файла (**не стирает**) | `echo "Bye" >> file.txt` |
| `$` | Переменная | Подставляет значение переменной | `echo $HOME` |
| `=` | Присваивание | Задает значение переменной | `name="Amal"` |

### Кавычки имеют значение!
- **Двойные `" "`**: Текст интерпретируется. Переменные внутри подставляются.
```bash
  echo "Привет, $USER"  # Выведет: Привет, amal
```
- **Одинарные `' '`**: Текст берется "как есть". Переменные НЕ подставляются.
```bash
  echo 'Привет, $USER'  # Выведет: Привет, $USER
```
- **Обратный слэш `\`**: Экранирует следующий символ (делает его обычным текстом).

## 5. Переменные и ввод/вывод

### Создание переменных
```bash
my_var="Значение"      # Строка в кавычках
count=10               # Число без кавычек
file_content=$(cat ./data.txt)  # Результат команды в переменную
```
⚠️ **Важно:** Не ставь пробелы вокруг знака `=`! (`var = 1` — ошибка, `var=1` — верно).

### Ввод данных
```bash
read user_input        # Ждет ввода от пользователя
```

### Код возврата ($?)
Любая команда возвращает код успеха:
- `0` — успех
- `1` (или другое число) — ошибка
Этот код хранится в переменной `$?` и используется в условиях.

## 6. Условия и Циклы

### Условие if
Проверяет, выполняется ли условие.
```bash
if [ -z "$USER" ]; then   # Если переменная USER пуста
    echo "Введите имя:"
    read USER
fi
```

### Цикл for (перебор)
Выполняет действие для каждого элемента списка.
```bash
for i in 1 2 3 4 5
do
    echo "Номер: $i"
done
```

### Цикл while (пока верно)
Выполняется, пока условие **ИСТИНА**.
```bash
x=1
while [ $x -le 5 ]    # Пока x меньше или равен 5
do
    echo "x = $x"
    x=$(( $x + 1 ))   # Увеличиваем x, иначе будет бесконечный цикл!
done
```

### Цикл until (пока неверно)
Выполняется, пока условие **ЛОЖЬ** (останавливается, когда станет истиной).
```bash
counter=0
until [ $counter -gt 5 ]  # Пока counter НЕ больше 5
do
    echo "Counter: $counter"
    ((counter++))
done
```

## 7. Функции

Функция — это именованный блок кода, который можно вызывать много раз. Аргументы передаются как `$1`, `$2` и т.д.

```bash
# Объявление функции
greet() {
    echo "Привет, $1! Твой ID: $2"
}

# Вызов функции
greet "Амаль" "007"
greet "Тест" "123"
```
*Вывод:*
```text
Привет, Амаль! Твой ID: 007
Привет, Тест! Твой ID: 123
```

## 8. Редакторы текста

Для работы в терминале нужно уметь редактировать файлы. Есть два основных пути:

### Nano (для новичков)
Простой, интуитивный редактор. Команды написаны внизу экрана.
- Поиск: `Ctrl+W`
- Сохранить: `Ctrl+O` → Enter
- Выйти: `Ctrl+X`

### Vi / Vim (для профи)
Мощный редактор с режимами (обычный, вставка, командный). Работает везде, даже на серверах без GUI.
- **Vi**: Базовая версия, есть почти во всех Unix-системах.
- **Vim**: Улучшенная версия ("Vi IMproved"). Поддерживает плагины, подсветку синтаксиса, макросы.
- **Hotkeys**: Управление полностью с клавиатуры (без мыши). Например, `i` — режим вставки, `Esc` — выход, `:wq` — сохранить и выйти.

*Совет: Начни с Nano. Когда почувствуешь уверенность — попробуй Vim.*

## 1. Что такое Linux и POSIX

**UNIX** — стандарт операционных систем с общими принципами архитектуры.
**POSIX** (Portable Operating System Interface for Unix) — набор стандартов, описывающих:
- Интерфейсы между ОС и программами (системный API)
- Библиотеку языка C
- Набор приложений и их интерфейсов

Именно благодаря POSIX скрипты работают одинаково в Ubuntu, Debian, CentOS и других дистрибутивах.

## 2. Файловая система Linux

Всё начинается с корня `/`. Структура по стандарту POSIX:

```
/                    ← корень (всё начинается отсюда)
├── bin/             ← основные команды (ls, cp, bash)
├── boot/            ← файлы загрузчика системы
├── etc/             ← конфиги системы (cron, сети, пользователи)
├── home/            ← домашние папки пользователей
│   └── amal/        ← моя личная комната
├── root/            ← домашняя папка суперпользователя root
├── sbin/            ← системные команды (только для root)
├── usr/             ← программы пользователей
├── var/             ← переменные данные (логи, кэш)
├── tmp/             ← временные файлы (очищаются при перезагрузке)
├── mnt/             ← точка монтирования внешних устройств
└── opt/             ← дополнительное ПО
```

### Основные сокращения путей
- `/` — корневой каталог
- `.` — текущая директория
- `..` — директория на уровень выше
- `~` — домашняя папка текущего пользователя (`/home/amal`)
- Абсолютный путь: начинается с `/` (например, `/usr/bin/`)
- Относительный путь: от текущей папки (например, `~/.ssh`)

## 3. Навигация и основные команды

### Где я нахожусь?
```bash
pwd              # Print Working Directory — полный путь
whoami           # Кто я (имя пользователя)
hostname         # Имя компьютера
```

### Что здесь лежит?
```bash
ls               # Список файлов
ls -l            # Длинный формат (права, размер, дата)
ls -a            # Показать скрытые файлы (начинаются с .)
ls -la           # Комбо: всё и сразу
```

### Перемещение
```bash
cd ~             # Вернуться домой
cd ..            # Подняться на уровень выше
cd ../..         # Подняться на два уровня
cd logs          # Зайти в папку logs
cd /etc          # Зайти в папку etc (абсолютный путь)
```

### Создание и удаление
```bash
mkdir practice                   # Создать папку
mkdir -p practice/{docs,logs}    # Создать папку с подпапками
touch file.txt                   # Создать пустой файл
rm file.txt                      # Удалить файл
rm -r folder/                    # Удалить папку со всем содержимым
```

### Копирование и перемещение
```bash
cp file.txt backup.txt           # Скопировать файл
cp -r folder/ backup/            # Скопировать папку
mv file.txt new_name.txt         # Переименовать
mv file.txt /tmp/                # Переместить в другую папку
```

## 4. Работа с содержимым файлов

```bash
cat file.txt                     # Вывести весь файл
head -n 5 file.txt               # Первые 5 строк
tail -n 5 file.txt               # Последние 5 строк
tail -f file.txt                 # Следить за файлом в реальном времени (для логов)
grep "слово" file.txt            # Найти строки со словом
grep -i "слово" file.txt         # Поиск без учёта регистра
```

### Перенаправление вывода
```bash
echo "текст" > file.txt          # Записать в файл (перезапишет!)
echo "текст" >> file.txt         # Дописать в конец файла
command 2>&1                     # Направить ошибки туда же, куда обычный вывод
command > /dev/null              # Выбросить вывод в "чёрную дыру"
command | grep "слово"           # Передать вывод другой команде (pipe)
```

## 5. Права доступа к файлам

Каждый файл имеет 10 символов прав: `drwxr-xr-x`

```
d  rwx  r-x  r-x
│   │    │    └── Другие (others): читать + заходить
│   │    └── Группа (group): то же самое
│   └── Владелец (user): читать + писать + заходить
└── Тип: d=папка, -=файл, l=ссылка, s=сокет
```

**Буквы прав:**
- `r` (read, 4) — читать
- `w` (write, 2) — писать/менять
- `x` (execute, 1) — запускать (для папок = заходить внутрь)
- `-` — права нет

### Цифровые коды прав (удобнее!)
| Код | Права | Значение |
|-----|-------|----------|
| 777 | rwxrwxrwx | Все могут всё (⚠️ опасно!) |
| 755 | rwxr-xr-x | Владелец всё, остальные читают+заходят (скрипты, папки) |
| 644 | rw-r--r-- | Владелец читает+пишет, остальные только читают (файлы) |
| 600 | rw------- | Только владелец (приватные файлы, SSH-ключи) |

### Изменение прав и владельца
```bash
chmod +x script.sh               # Добавить право на выполнение (символьный способ)
chmod 755 script.sh              # Установить права 755 (цифровой способ)
chmod 644 file.txt               # Установить права 644
chown user file.txt              # Сменить владельца (нужен sudo)
chown -R user folder/            # Сменить владельца папки рекурсивно
chgrp group file.txt             # Сменить группу
```

## 6. Пользователи и группы

### Создание пользователя
```bash
# Низкоуровневый способ (для скриптов)
sudo useradd -m -s /bin/bash newuser
sudo passwd newuser

# Интерактивный способ (для ручной работы в Ubuntu)
sudo adduser newuser
```
*Флаг `-m` создаёт домашнюю папку, `-s /bin/bash` устанавливает bash.*

### Управление
```bash
sudo passwd user                 # Задать/сменить пароль
sudo usermod -aG sudo user       # Добавить в группу sudo (админские права)
sudo usermod -aG docker user     # Добавить в группу docker
su - user                        # Переключиться на другого пользователя
exit                             # Выйти обратно
```

### Где хранится информация
```bash
cat /etc/passwd                  # Список всех пользователей
cat /etc/group                   # Список групп
cat /etc/sudoers                 # Кто имеет права sudo
```

**Важно:** В Ubuntu админская группа называется `sudo`, в CentOS/RHEL — `wheel`.

## 7. Sudo и суперпользователь

```bash
sudo command                     # Выполнить команду от имени root
sudo -i                          # Войти в сессию root
sudo su -                        # То же самое (стать root)
su -                             # Войти как root (нужен пароль root)
```

**Правила безопасности:**
- Не работай постоянно под root — используй `sudo` для конкретных команд
- История команд (`history`) сохраняется для каждого пользователя отдельно
- Пароль `sudo` кэшируется на 15 минут
- `sudo` записывает все действия в логи (аудит)

### История команд
```bash
history                          # Показать всю историю
history | grep "слово"           # Найти команду в истории
Ctrl+R                           # Поиск по истории в реальном времени
```

## 8. Пакетные менеджеры

### APT (Ubuntu, Debian)
```bash
sudo apt update                  # Обновить списки пакетов
sudo apt upgrade                 # Обновить все программы
sudo apt install nginx           # Установить программу
sudo apt remove nginx            # Удалить (оставить конфиги)
sudo apt purge nginx             # Удалить полностью (включая конфиги)
sudo apt autoremove              # Удалить ненужные зависимости
sudo apt clean                   # Очистить кэш скачанных пакетов
apt search nginx                 # Поиск программы
```

### YUM/DNF (CentOS, RHEL, Fedora)
```bash
sudo yum install nginx           # Установить (CentOS 7)
sudo dnf install nginx           # Установить (CentOS 8+, Fedora)
```

## 9. Мониторинг системы

### Загрузка системы
```bash
uptime                           # Время работы и load average
top                              # Процессы в реальном времени (q — выйти)
htop                             # Улучшенный top (нужно установить)
atop                             # Продвинутый мониторинг
```

**Load Average** — средняя нагрузка на CPU за 1, 5, 15 минут:
- Меньше количества ядер — всё ок
- Равно — загрузка 100%
- Больше — процессы в очереди, система "задыхается"

### Память
```bash
free -h                          # Оперативная память (human-readable)
free -m                          # В мегабайтах
```

```bash
df -h                            # Использование дисков
df -h /                          # Только корневой раздел
du -sh folder/                   # Размер конкретной папки
```

### Сеть
```bash
hostname -I                      # IP-адреса машины
ip a                             # Все сетевые интерфейсы
ss -tlnp                         # Открытые порты (современная замена netstat)
netstat -tlnp                    # Открытые порты (старая команда)
ping google.com                  # Проверить связь
```

### Процессы
```bash
ps aux                           # Все процессы
ps aux | grep nginx              # Найти процесс nginx
kill PID                         # Завершить процесс по ID
kill -9 PID                      # Принудительно завершить
```

## 11. SSH — удалённое подключение

### Подключение по паролю
```bash
ssh user@192.168.1.100           # Подключиться к серверу
ssh -p 2222 user@server          # Нестандартный порт
```

### SSH-ключи (без пароля!)
```bash
ssh-keygen -t ed25519            # Создать пару ключей
ssh-copy-id user@server          # Скопировать публичный ключ на сервер
```
После этого можно подключаться без пароля. Ключи лежат в `~/.ssh/`:
- `id_ed25519` — приватный ключ (никому не показывать!)
- `id_ed25519.pub` — публичный ключ (можно давать серверам)

### Файловый менеджер mc
```bash
sudo apt install mc              # Установить Midnight Commander
mc                               # Запустить (двухпанельный файловый менеджер)
```
Удобно для навигации, копирования, редактирования файлов.

## 15. Git — основы для DevOps

```bash
git clone <url>                        # Скачать репозиторий
git add file.txt                       # Добавить файл в индекс
git add .                              # Добавить все изменения
git commit -m "сообщение"              # Сохранить изменения
git push origin main                   # Отправить на GitHub
git pull origin main                   # Скачать изменения с GitHub
git pull --rebase origin main          # Скачать и аккуратно встроить свои коммиты
git status                             # Текущее состояние репозитория
git log --oneline                      # История коммитов
```

**Conventional Commits** — стандарт сообщений:
- `feat:` — новая функция
- `fix:` — исправление ошибки
- `docs:` — изменение документации
- `refactor:` — переработка кода без изменения функционала

# 🐧 Основы Linux и навигация

## 1. Навигация по файловой системе

### Где я нахожусь?
```bash
pwd
```
Показывает полный путь к текущей папке (Print Working Directory). Например: `/home/amal`.

### Что здесь лежит?
```bash
ls -la
```
- `ls` = список файлов.
- `-l` = длинный формат (показывает права, размер, дату).
- `-a` = показать скрытые файлы (те, что начинаются с точки `.`).

**Цвета в терминале:**
- 🔵 Синие — папки.
- 🟢 Зеленые — исполняемые файлы (скрипты).
- ⚪ Белые — обычные файлы.
- 🔴 Красные со стрелкой — символические ссылки (ярлыки).

### Как перемещаться?
```bash
cd ~          # вернуться домой (/home/amal)
cd ..         # подняться на уровень выше
cd logs       # зайти в папку logs
```
*Важно:* `~` (тильда) — это всегда твоя домашняя папка. `.` (точка) — это папка, в которой ты стоишь прямо сейчас.

## 2. Права доступа (drwxr-xr-x)

Каждый файл имеет 10 символов прав:
```text
d  rwx  r-x  r-x
│   │    │    └── Другие пользователи: читать + заходить
│   │    └── Группа: то же самое
│   └── Владелец: читать + писать + заходить
└── Тип: d=папка, -=файл, l=ссылка
```

**Буквы:**
- `r` (read) — читать.
- `w` (write) — писать/менять.
- `x` (execute) — запускать (для папок = заходить внутрь).
- `-` — права нет.

**Как сделать скрипт исполняемым?**
```bash
chmod +x first_script.sh
```

## 3. Системная информация

### Кто я?
```bash
whoami
```
Показывает имя текущего пользователя.

### Сколько работает система?
```bash
uptime
```
Вывод: `17:15:52 up 24 min, 1 user, load average: 2.45, 2.61, 1.92`

**Load Average** — средняя нагрузка на CPU за 1, 5 и 15 минут.
- Если число **меньше** количества ядер CPU — всё ок.
- Если **больше** — система перегружена, процессы ждут очереди.

## 4. Мониторинг ресурсов

### Оперативная память (RAM)
```bash
free -h
```
*Главное правило:* Смотри на колонку **available**, а не free! Linux использует свободную память под кэш (buff/cache) для ускорения работы. Если программе понадобится память, кэш автоматически освободится.

### Диск
```bash
df -h
```
Показывает, сколько места на дисках. `-h` делает вывод понятным для человека (в G и M, а не в байтах).

### Процессы в реальном времени
```bash
top
```
Показывает, какие процессы жрут CPU и память. Нажми `q`, чтобы выйти.

## 5. Структура файловой системы Linux

Всё в Linux начинается с корня `/`.

```text
/                    ← корень (всё начинается отсюда)
├── bin/             ← основные команды (ls, cp, bash)
├── etc/             ← конфиги системы (тут живёт cron, сети, пользователи)
├── home/            ← домашние папки пользователей
│   └── amal/        ← моя личная комната
├── var/             ← переменные данные (логи, кэш)
├── tmp/             ← временные файлы (очищаются при перезагрузке)
└── usr/             ← программы пользователей
```

## 6. Полезные советы

1. **Скрытые файлы:** Всё, что начинается с точки (например, `.bashrc`, `.ssh`), скрыто от обычного `ls`. Флаг `-a` показывает их.
2. **sudo:** Выполняет команду от имени суперпользователя (root). Пароль кэшируется на 15 минут.
3. **apt vs apt-get:** `apt` — для людей в терминале, `apt-get` — для скриптов (стабильный интерфейс).
4. **Перенаправление вывода:**
   - `> file.txt` — записать вывод в файл (перезапишет его).
   - `>> file.txt` — дописать вывод в конец файла.
   - `2>&1` — направить ошибки туда же, куда и обычный вывод.
   - `/dev/null` — "черная дыра", выбрасывает вывод в никуда.
